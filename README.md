\# Casalibros



Home library manager built with Spring Boot microservices. Track your books, your reading progress and the books you lend to friends and family.



\## Tech stack



Java 17, Spring Boot, PostgreSQL, Docker, Kubernetes, GitHub Actions, Spring Security (JWT), Angular.
